# Week 4 — Interactive To-Do List App

## About the Project

This is a themed, interactive To-Do List application built using HTML, Tailwind CSS v4, Vite, and vanilla JavaScript.

The application helps users organize daily tasks, track progress, and save their tasks in the browser.

## Getting Started

### Prerequisites
Install Node.js and npm.

### Installation

1. Clone this repository:

   `git clone https://github.com/belise17/week4-todo-app.git`

2. Open the project folder:

   `cd week4-todo-app`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in your terminal.

## Usage

- Enter a task and add it to your list.
- Mark tasks as completed when finished.
- Edit or delete tasks when needed.
- Use filters and search to find tasks.
- Choose a priority if the feature is available in your current version.
- Clear completed tasks when you no longer need them.

Tasks are saved in the browser using localStorage.
